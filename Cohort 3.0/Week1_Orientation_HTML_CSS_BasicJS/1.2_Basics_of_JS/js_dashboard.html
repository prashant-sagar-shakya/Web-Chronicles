Module 1

1. What is JavaScript?

JavaScript is a versatile, high-level language that powers the web. It is unique due to being Interpreted (runs line-by-line), Single-Threaded (one task at a time), and having automatic Memory Management.

Source File: Intro.js 
// [1] Interpreted Language: JS reads code live.
console.log("Interpreted means I run line-by-line!");

// [2] Dynamically Typed: Flexible variables.
let myValue = 100;
myValue = "Hello"; // No error!

// [3] Single Threaded: One task at a time.
console.log("I have one main call stack.");

3. Decision Making & Logic

If-Else statements and Logical Operators (&&, ||) are the tools we use to build intelligent software.

Source File: If-else.js 
if (time < 12) {
    console.log("Good Morning!");
} else {
    console.log("Good Afternoon!");
}

// Multiple conditions (Else-If ladder)
if (age < 13) { console.log("Child"); }
else if (age < 20) { console.log("Teen"); }
else { console.log("Adult"); }
Assignment 3: Max of Three Numbers (Full Code) 
function findMax(a, b, c) {
    if (a >= b && a >= c) return a;
    else if (b >= a && b >= c) return b;
    else return c;
}
