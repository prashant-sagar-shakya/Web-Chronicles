SYNCHRONOUS VS ASYNCHRONOUS (Easy Explanation)
===========================================================

1. WHAT IS SYNCHRONOUS?
-----------------------
Definition: Synchronous means "sequential." The code runs one line at a time.
The next task must wait for the previous task to finish.

Real-life Example: A Queue at an ATM.
You cannot use the ATM until the person in front of you finishes. 
If the person in front takes 10 minutes, you are STUCK waiting for 10 minutes.

In Code: 
If you read a big file synchronously, your whole website "freezes" 
until the file is finished reading.


2. WHAT IS ASYNCHRONOUS?
------------------------
Definition: Asynchronous means "non-blocking." The code starts a task 
but moves to the next line immediately without waiting.

Real-life Example: Ordering Pizza.
You call the pizza shop and place an order. You don't stay on the phone 
for 30 minutes waiting for them to cook. You hang up, watch a movie, or 
do your homework. When the pizza arrives, they ring your doorbell (this 
is like a "callback").

In Code:
You can start reading a file or fetching data from the internet, and 
JavaScript will keep running other parts of your code. When the data 
is ready, it notifies you.


3. THE MAIN DIFFERENCE
----------------------
- Synchronous = STOP and WAIT.
- Asynchronous = START and MOVE ON.
