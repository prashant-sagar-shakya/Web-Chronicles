# Terminal Commands Guide

This file provides a detailed explanation of common terminal commands used in web development and general system navigation.

---

## 1. pwd (Print Working Directory)
- This command displays the absolute path of the directory you are currently in. It is very useful when you are navigating deep into nested folders and need to know your exact location.
- **Example:** `pwd` might return `/Users/username/Projects/my-app`.

## 2. cd (Change Directory)
- This command is used to move from one folder to another. 
    - `cd folder_name`: Moves into a specific folder.
    - `cd ..`: Moves back to the parent folder.
    - `cd ~`: Takes you to the home directory.
- **Example:** `cd Desktop`

## 3. ls (List)
- It lists all the files and folders inside the current directory. You can use flags like `ls -l` for a detailed list or `ls -a` to see hidden files.
- **Example:** `ls`

## 4. mkdir (Make Directory)
- This command creates a new folder.
- **Example:** `mkdir New_Project` creates a folder named "New_Project".

## 5. touch
- It is the simplest way to create a new, empty file.
- **Example:** `touch index.html` creates an empty file named index.html.

## 6. cat (Concatenate)
- While it can combine files, it is most commonly used to quickly read and display the content of a file directly in the terminal window.
- **Example:** `cat README.md`

## 7. vi (Visual Editor)
- A terminal-based text editor. It is powerful but has a learning curve. 
    - Press `i` to enter "Insert mode" (to start typing).
    - Press `Esc` and type `:wq` to save and quit.
- **Example:** `vi config.txt`

## 8. mv (Move / Rename)
- This command serves two purposes: moving a file to a different folder or renaming an existing file.
- **Example:** `mv file.txt new_name.txt` (Renames the file)

## 9. cp (Copy)
- It creates a copy of a file or directory.
- **Example:** `cp original.js backup.js`

## 10. nvm (Node Version Manager)
- A tool used to install and switch between different versions of Node.js on the same machine. This is crucial when working on multiple projects that require different Node versions.
- **Example:** `nvm use 18`

## 11. npm (Node Package Manager)
- The world's largest software registry. It is used to install libraries, frameworks, and tools needed for your JavaScript/Node.js projects.
- **Example:** `npm install express`

## 12. node
- The command used to run JavaScript files outside of the browser. It triggers the Node.js runtime environment.
- **Example:** `node server.js`

---

# Hinglish Summary

1.  **pwd**: Abhi main kis folder mein hoon? Ye janne ke liye.
2.  **cd**: Ek folder se doosre folder mein "jaane" (navigate) ke liye.
3.  **ls**: Folder ke andar kya-kya files aur folders hain, unki list dekhne ke liye.
4.  **mkdir**: Ek naya folder banane ke liye.
5.  **touch**: Ekdum naya aur khaali file banane ke liye.
6.  **cat**: File ke andar kya likha hai, wo screen par hi padhne ke liye.
7.  **vi**: Terminal ke andar file edit karne wala tool.
8.  **mv**: File ko move karne ya uska naam badalne (rename) ke liye.
9.  **cp**: Kisi file ki copy banane ke liye.
10. **nvm**: Node.js ke versions switch karne ke liye.
11. **npm**: External libraries (packages) install karne ke liye.
12. **node**: JavaScript file ko run karne ke liye.
