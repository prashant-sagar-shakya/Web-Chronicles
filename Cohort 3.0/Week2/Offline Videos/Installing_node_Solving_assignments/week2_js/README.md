# Week 2 - JavaScript Assignments

This repository contains basic JavaScript assignments focused on logic and array manipulations.

## Assignments

### Easy
1. **Anagram**: A function to check if two strings are anagrams of each other.
2. **Find Largest Element**: A function to find the largest element in an array.

## How to Run
1. Navigate to this directory.
2. Run `npm install` to install dependencies (like Jest).
3. To run tests for all assignments, use:
   ```bash
   npx jest tests/
   ```
4. To run tests for a specific assignment, use:
   ```bash
   npx jest tests/anagram.test.js
   ```
